# CS2 Skin Monitor — сайт

Адаптивное веб-приложение для сравнения цен LIS-SKINS и CS.Market. Работает на Node.js 18+ без сторонних npm-зависимостей.

## Запуск локально

```bash
npm start
```

Откройте `http://localhost:3000`.

## Публикация

Проект можно развернуть на Render, Railway или другом хостинге, который запускает Node.js-приложения.

- Build command: не требуется
- Start command: `npm start`
- Runtime: Node.js 18 или новее

После публикации добавьте в Environment Variables хостинга:

- `LIS_API_URL` — точный URL endpoint из документации LIS API.
- `LIS_API_KEY` — ваш API-ключ.
- `LIS_API_KEY_HEADER` — имя заголовка для ключа; по умолчанию `X-API-KEY`.

Затем перезапустите приложение. Не вставляйте секретный ключ в HTML/JavaScript и не отправляйте его в чат.

## Подключение LIS-SKINS — важное замечание

В этой сборке серверный прокси уже предусмотрен, поэтому браузерный CORS не должен блокировать запрос к LIS API. Однако точный URL, имя заголовка авторизации, параметры фильтрации и структура ответа зависят от документации и прав вашего API-аккаунта. В текущей сборке используется заголовок `X-API-KEY` по умолчанию и базовая нормализация типичных полей ответа. Если документация LIS задаёт другие значения, укажите правильный URL/заголовок и при необходимости скорректируйте `toItems()` в `public/app.js`.

## CS.Market

Пока поддержан импорт CSV-файла с колонками названия предмета и цены. Прямое подключение CS.Market API не заявляется, пока не подтверждены доступный endpoint и формат авторизации.
